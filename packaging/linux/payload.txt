# The paths every Linux format ships for a package: <package> <path>. scripts/ci/assert-payload-parity.sh
# checks each built .deb, .rpm and .pkg.tar.zst against it. A package is the artifact that ships
# its first row. On Arch, usr/libexec/rubyfunk/ reads usr/lib/rubyfunk/, except for seats, whose
# units and doctor name /usr/libexec. check-packaging-policy.py finds each seats file in the Nix
# and Steam Deck recipes too.
