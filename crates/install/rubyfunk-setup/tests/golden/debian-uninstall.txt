==> Uninstalling the host (https://docs.punktfunk.unom.io/docs/uninstall)
  + systemctl --user disable --now rubyfunk-host rubyfunk-web rubyfunk-scripting 2>/dev/null || true
  + sudo apt purge -y rubyfunk-host rubyfunk-web rubyfunk-scripting
  + sudo rm -f /etc/apt/sources.list.d/rubyfunk.list /etc/apt/keyrings/rubyfunk.asc
  + sudo apt update

  Removed. Left on purpose: ~/.config/rubyfunk (identity, pairings, host.env, plugins — a reinstall
  picks them up), the rubyfunk, rubyfunk-door and rubyfunk-update groups, and any firewall
  rules you opened.
  The one-command cleanups for each are on https://docs.punktfunk.unom.io/docs/uninstall#linux-hosts
